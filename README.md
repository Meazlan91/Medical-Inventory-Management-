## Main Features
- Quick Sale (scan → pay → print)
- Inventory + Purchase + Returns
- Near-expiry list & stock adjust
- Reports + CSV export
- Customers, Expenses, Users
- Global search (Ctrl+K), WhatsApp bill share
- Thermal print settings (58/80mm)
